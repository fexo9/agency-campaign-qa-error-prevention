## The 7 gates

1. **Budget & Pacing** — daily vs lifetime, extra zeros, end date, bid strategy,
   day-1 cap, flight arithmetic.
2. **Targeting & Audience** — geo, audience match, exclusions, overlap, device, language.
3. **Tracking & UTM** — UTM on every link, format validation, no recycled names,
   pixel firing on the real action, CAPI dedup, consent gating.
4. **Creative & Copy** — approved version, headline-offer match, no placeholders,
   prices/dates correct, disclaimers, mobile render.
5. **Landing Page** — URL live, form submits end-to-end, thank-you page fires,
   loads fast on mobile, CTA works, no broken links.
6. **Approvals & Compliance** — client sign-off on file for THIS campaign, covering
   the exact creative + budget + dates, no unsupportable claims, two-person check.
7. **Post-Launch Controls** — day-1 check scheduled, kill-switch owner named,
   reporting cadence set, incident log ready, end-of-flight review set.
